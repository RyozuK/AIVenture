# AIVenture

> An AI-powered MUD-like text adventure game with procedurally generated dungeons, LLM-driven narratives, and a pluggable architecture.

## Features

- **Procedural dungeon generation** — rooms, items, entities, and features generated by an LLM
- **Combat system** — attack monsters with LLM-resolved outcomes, XP/loot drops, leveling
- **Equipment** — equip weapons, armor, and accessories with slot validation and stat bonuses
- **Items** — potions, consumables, keys, quest items with charges and effects
- **NPCs & Dialogue** — talk to NPCs for quests, trades, and flavor
- **Quest system** — auto-advancing objectives (kill, collect, explore), reward granting
- **Death & respawn** — configurable death penalties, full heal on respawn
- **Save system** — auto-save (interval, quest-complete, death, room-gen), manual save, slot management
- **World export/import** — share or backup your dungeon as JSON
- **Plugin system** — entry-point based discovery for custom actions, tools, and providers
- **Pluggable LLM** — OpenAI, Ollama, or any OpenAI-compatible API
- **Pluggable persistence** — JSON, SQLite, or in-memory providers
- **Pluggable clients** — console, WebSocket, Discord

## Configuration

Copy `config.example.yaml` to `config.yaml` and customize:

```yaml
llm:
  provider: "ollama"         # openai | ollama | custom
  endpoint: "http://localhost:11434/v1"
  model: "llama3.1"
  temperature: 0.9
  max_tokens: 1024

persistence:
  provider: "sqlite"         # json | sqlite | memory
  path: "saves/saves.db"

client:
  type: "console"            # console | websocket | discord

discord:
  token: "${DISCORD_TOKEN}"  # Required for Discord mode
  bot_name: "AIVentureBot"
  reactions: true             # Add reaction quick-actions to messages
  allow_dms_only: true        # Restrict gameplay to DMs
```

See `config.example.yaml` for all options.

## Commands

| Command | Description |
|---|---|
| `north`, `south`, `east`, `west`, `up`, `down` | Move in direction |
| `go north`, `walk south` | Move with verb prefix |
| `look` / `l` | Look at current room |
| `look at <target>` / `examine` | Examine item or entity |
| `take <item>` / `get` | Pick up item |
| `drop <item>` | Drop item on ground |
| `inventory` / `i` | Show inventory |
| `equip <item>` | Equip item to slot |
| `unequip <slot>` | Remove equipped item |
| `use <item>` / `drink` | Use potion or consumable |
| `attack <target>` / `hit` | Attack entity |
| `search` / `rummage` | Search room |
| `talk <npc>` / `speak` | Talk to NPC |
| `quests` / `quest` | Show active quests |
| `stats` / `statistics` | Show game statistics |
| `save [slot]` | Save game |
| `export [path]` | Export world to JSON |
| `quit` / `q` | Quit game |

### Natural Language

The parser supports pronouns (`it`, `them`), prepositions (`with`, `on`), and freeform commands sent to the LLM:

- `attack it` — attacks the last mentioned entity
- `use it` — uses the last mentioned item
- `i try to sneak past the guard` — sent to LLM for interpretation

## Architecture

```
aiventure/
├── model/           # Pure dataclasses (no I/O)
│   ├── coords.py    # Position, Direction
│   ├── world.py     # World, Room + serialization
│   ├── entity.py    # Entity, Player
│   ├── item.py      # Item, Inventory
│   └── quest.py     # Quest, Objective, Reward
├── llm/             # LLM adapters and orchestration
│   ├── adapter.py   # LLMAdapter ABC
│   ├── adapters/    # OpenAI, Ollama, Custom
│   ├── service.py   # LLMService (tool calls, retry)
│   ├── tools.py     # 5 tool schemas
│   └── memory.py    # Context memory manager
├── controller/      # Game logic
│   ├── session.py   # GameSession (main controller)
│   ├── parser.py    # Natural language parser
│   ├── context.py   # Prompt context builder
│   └── actions/     # Action handlers
│       ├── combat.py
│       ├── death.py
│       ├── examine.py
│       ├── inventory.py
│       ├── move.py
│       ├── social.py
│       └── stats.py
├── persistence/     # Save/load system
│   ├── manager.py   # SaveManager
│   ├── provider.py  # SaveProvider ABC
│   └── providers/   # JSON, SQLite, Memory
├── client/          # Frontend clients
│   ├── base.py      # Client ABC
│   ├── protocol.py  # CommandRequest, CommandResult
│   ├── console.py   # ConsoleClient
│   ├── websocket.py # WebSocketClient
│   └── discord.py   # DiscordClient
├── utils/           # Config and logging
├── plugins.py       # Plugin discovery and registry
├── main.py          # Entry point
└── __main__.py
```

### MVC Separation

- **Model** — pure dataclasses, no async, no I/O
- **Controller** — `GameSession` dispatches commands via parser → action handlers
- **View** — `Client` implementations (console, WebSocket, Discord)

## Extending

### Adding a new action handler

```python
# aiventure/controller/actions/my_action.py
async def do_foo(session: "GameSession", target: str) -> dict:
    return {"narrative": f"You foo'd the {target}.", "state": {}}
```

Wire it in `session.py`:
```python
elif parsed.verb == "foo":
    from .actions.my_action import do_foo
    return await do_foo(self, parsed.target)
```

And add to `parser.py`:
```python
"foo": {"foo", "foobar"},
```

### Adding a new LLM adapter

Implement `LLMAdapter` ABC:
```python
from aiventure.llm.adapter import LLMAdapter, LLMResponse

class MyAdapter(LLMAdapter):
    async def chat(self, ...): ...
    async def generate_text(self, ...): ...
```

### Adding a new persistence provider

Implement `SaveProvider` ABC:
```python
from aiventure.persistence.provider import SaveProvider

class MyProvider(SaveProvider):
    async def save(self, slot_name: str, world_state: dict): ...
    async def load(self, slot_name: str) -> dict | None: ...
    async def delete(self, slot_name: str): ...
    async def list_slots(self) -> list[str]: ...
```

### Adding a plugin

Register via setuptools entry points:
```toml
[project.entry-points."aiventure.plugins"]
my_plugin = "my_plugin:register"
```

```python
def register(session):
    # Register custom handlers, tools, etc.
    pass
```
